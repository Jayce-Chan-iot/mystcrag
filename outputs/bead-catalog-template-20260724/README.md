# 玄矶 Mystcrag 珠子商品库导入模板 V1.0

本目录是对原模板的增量优化交付。原文件 `玄矶珠子商品库导入模板.xlsx` 保留在上一版输出目录，未被覆盖。

## 文件

- `玄矶珠子商品库导入模板_V1.0_简化优化版.xlsx`：主导入工作簿。
- `mystcrag_schema.json`：机器可读字段、枚举、外键和隔离规则。
- `validate_mystcrag_excel.py`：独立结构与业务校验脚本。
- `CHANGELOG.md`：相对原模板的变化说明。

## 推荐填写顺序

1. `水晶主数据`：一种水晶一行。
2. `珠子SKU`：每个“水晶种类 + 形状 + 尺寸 + 工艺”一行。
3. `库存批次`：同一 SKU 的不同进货批次分别记录。
4. `图片资产`：一张图片一行，保存来源、授权、实拍/AI 属性。
5. `配件SKU`：继续使用原模板的配件录入结构。
6. `AI分析结果`：可选，第一阶段可以不填写。

## 品质口径

`市场品质等级` 只允许：

- `COMMERCIAL_A`：普通商业 A 级
- `NEAR_COMMERCIAL_A`：接近商业 A 级
- `UNKNOWN`：无法确认

`品质信息来源` 只允许：

- `USER_CONFIRMED`：用户确认
- `SUPPLIER_CLAIM`：供应商描述
- `MARKET_DESCRIPTION`：市场常用描述
- `UNKNOWN`：无法确认

这里的商业 A 级是市场和供应商常用描述，不代表统一国家标准、实验室评级或宝石学鉴定结论，也不对应固定的透明度、净度或瑕疵标准。

正式人工录入区不要求填写透明度、棉絮、冰裂、黑点、矿缺、包裹体、颜色均匀度或处理方式。不同水晶种类的商业 A 级表现可以不同。

## AI 分析隔离

`AI分析结果` 的所有字段均为可选，内容只能解释为模型估算：

- 不能作为矿物学或鉴定结论；
- 不能自动覆盖水晶主数据、珠子 SKU 或库存批次；
- 不确定时填写 `UNKNOWN`；
- 低置信度应填写 `requires_manual_review=TRUE`；
- 第一阶段可以只保留表结构，不运行图片识别。

## 导入状态

正式导入表使用以下状态：

- `可导入`
- `请补全必填`
- `ID重复`
- `关联不存在`
- `格式错误`
- `枚举错误`
- `待人工复核`
- `待填写`

状态只检查可确认信息，例如 ID、外键、枚举、尺寸、数量、价格、图片路径和权限。不会因为专业鉴定细分字段为空而阻止导入。

工作簿设置为打开时自动完整重算。若某个办公软件未立即刷新状态列，可在 Excel 中执行一次“全部重新计算”。

## 运行校验

需要 Python 3.10+ 和 `openpyxl`：

```bash
python -m pip install openpyxl
python validate_mystcrag_excel.py
```

也可以校验另一个文件：

```bash
python validate_mystcrag_excel.py /path/to/workbook.xlsx
```

校验脚本会检查：

- 文件能否正常打开；
- 原始模板哈希是否未变化；
- 工作表、表头、表格、公式、条件格式和数据验证；
- 空白必填数字不会被当作有效数字；
- 重复 ID 和外键错误能被识别；
- 品质枚举和图片权限规则；
- 专业鉴定字段未进入正式人工录入区；
- AI 分析结果与正式商品数据隔离；
- 原示例数据仍存在。

## AI 设计库使用建议

推荐珠子时优先使用：

- 已人工确认；
- 市场品质为 `COMMERCIAL_A` 或 `NEAR_COMMERCIAL_A`；
- 有真实批次图片；
- 有库存和有效价格；
- 使用权限清晰；
- 明确允许进入 AI 设计库。

没有透明度、棉絮或冰裂标签不应成为排除商品的理由，真实细节由当前批次实拍图向用户展示。

商品页面统一提示：

> 天然水晶不同珠子及不同批次可能存在颜色、纹理、棉裂和包裹体差异，具体以当前批次实拍图片为准。

## 后续图片采集边界

本版不执行网络采集。后续程序应只采集明确指定的水晶种类，默认目标为普通商业 A 级或接近 A 级；不清楚品质时写 `UNKNOWN`，自动采集数据进入待审核区，保存原始链接和权限，进行去重，并区分真实图片与 AI 生成图片。
