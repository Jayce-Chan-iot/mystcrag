# CHANGELOG

## V1.0 简化优化版 — 2026-07-24

### 原模板分析

- 原工作簿包含 `使用说明`、`水晶主数据`、`珠子SKU`、`配件SKU`、`字段字典` 5 张可见工作表。
- 已有紫色标题/表头主题、示例数据、Excel 表格、下拉验证、条件格式和导入状态公式。
- 原模板未包含 `库存批次`、`图片资产` 或 `AI分析结果`。
- 原模板的 `珠子SKU` 已包含币种、售价、成本、可用库存、资产键和上架状态等业务字段。
- 原模板未发现透明度、棉絮、冰裂、黑点、矿缺、包裹体、颜色均匀度、天然程度或处理方式推断等专业鉴定字段，因此没有删除或搬迁旧数据。

### 保留

- 保留原始文件，不覆盖。
- 保留紫色视觉风格、主要工作表布局、表格结构、示例水晶、示例珠子、示例配件、字段字典和已有业务字段。
- 保留币种、售价、成本和可用库存字段，并在 `珠子SKU` 表头标记为“保留业务字段”。
- 保留原模板的商品/材质/模型/纹理资产字段。

### 新增

- `珠子SKU` 新增简化品质字段：
  - 市场品质等级
  - 品质信息来源
  - 品质备注
  - 是否经过人工确认
  - 是否适合进入AI设计库
- `珠子SKU` 新增尺寸、孔径、切面、计价单位、包装数量、串信息和默认损耗率字段。
- 新增 `库存批次`，用于区分进货批次、库存数量、批次成本、简单外观备注、实拍与人工确认状态。
- 新增 `图片资产`，实行“一张图片一行”，记录来源、授权、真实实拍、AI 图片疑似、当前货品代表性和人工复核。
- 新增隔离的 `AI分析结果`，全部字段可选，仅用于模型估算。
- 新增隐藏的 `_枚举` 工作表，为长枚举下拉提供稳定数据源。
- 扩展 `字段字典` 和 `使用说明`，加入商业品质口径、AI 隔离和商品页统一提示。
- 新增 `mystcrag_schema.json` 和独立校验脚本。

### 导入状态与公式修正

- 状态统一为：可导入、请补全必填、ID重复、关联不存在、格式错误、枚举错误、待人工复核、待填写。
- 增加 product_id、sku、lot_id、image_id 的重复检查。
- 增加 crystal_id、sku、lot_id 的外键检查。
- 增加商业品质、品质来源、图片权限、布尔字段等枚举检查。
- 必填数字使用 `ISNUMBER` 和显式空白检查，不再让空白单元格因 `>=0` 比较而被误判为有效。
- 可选数字只有在填写后才进行数字和范围检查。
- 申请进入 AI 设计/推荐库但品质为 `UNKNOWN`、未人工确认、缺少实拍或未通过复核时，状态进入 `待人工复核`。
- 工作簿设置为打开时自动完整重算。

### 专业鉴定字段处理

- 正式人工录入区不新增、不要求、不校验以下字段：
  - 透明度等级
  - 颜色浓度或颜色均匀度
  - 棉絮、冰裂、黑点、矿缺、表面瑕疵程度
  - 包裹体类型
  - 抛光等级
  - 天然程度
  - 处理方式推断
- 若未来需要计算机视觉分析，只能写入 `AI分析结果`，不得覆盖正式商品数据。

### 兼容性

- 原示例 product_id、sku、crystal_id 和配件数据继续保留。
- 原字段语义通过保留列或扩展字段字典维持，可继续读取旧数据。
- 未修改应用代码、数据库 schema、API contract 或原始 Excel 文件。
