# Product Requirement

## User Flow

Landing page -\> AI exploration or direct creation -\> questionnaire when
applicable -\> AI design -\> 2.5D DIY -\> saved design -\> order snapshot.

## Modules

-   AI Designer
-   DIY Editor
-   Crystal Library
-   Design Gallery
-   Order System

## Goal

Create the smallest trustworthy product loop in which a desktop or mobile user
can feel understood, create a bracelet through a direct 2.5D editor, retain the
design, and obtain server-authoritative order information.

The MVP interaction surface is a front-facing, image-based 2.5D bracelet
editor. Three.js remains an optional reusable visualization capability and is
not a release requirement for the primary DIY route.
