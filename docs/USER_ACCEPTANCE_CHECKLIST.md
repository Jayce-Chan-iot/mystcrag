# 玄矶 Mystcrag 用户验收清单

预计 5–10 分钟。开始前按 `LOCAL_DEMO_GUIDE.md` 启动 PostgreSQL、Backend 和 Frontend。

## 核心验收

- [ ] 打开 `http://localhost:3000`，页面无 Mock 标识，可进入 AI 设计流程。
- [ ] 完成问卷：填写当前状态、色彩、风格、预算、腕围、文化偏好与个性化同意；至少排除一种材料。
- [ ] 提交后在桌面首屏横向看到三张方案卡，三者有不同名称、故事/依据和可见的材料节奏；价格与预算状态明确，底部“进入 DIY 调整”始终可见。
- [ ] 选择一套未超预算方案进入详情与 DIY；若选择超预算方案，系统要求显式确认。
- [ ] DIY 页面出现正面平面、图片材质的 2.5D 手串编辑区；不依赖 WebGL，点击珠子后能看到稳定的选中状态。
- [ ] 更换或删除珠材；等待 Backend 返回后确认 revision 增加，权威总价实时变化，且不会出现阻断编辑的大型价格确认面板。
- [ ] 从首页点击“直接进入 DIY”，确认不经过问卷；点击“开始 AI 设计”，确认仍进入六步问卷。
- [ ] 在 DIY 预览中切换“收缩成串 / 散开查看”，确认珠子平滑收紧且再次点击可恢复便于编辑的间距。
- [ ] 开始拖动珠子时确认圆形展示托盘边界出现删除提示；把珠子拖出托盘并松手后删除，托盘内部松手不会误删，未拖动时提示隐藏。
- [ ] 拖动珠子时确认珠子的大小、颜色、透明度、圆形轮廓和光影保持不变，且没有方形拖拽阴影。
- [ ] 通过增加/移除不同直径珠子确认“当前手围”实时变化；珠子与配件按实际毫米尺寸占据圆周空间，数量多时仍不会挤成一团。
- [ ] 当前组装长度小于 13.0cm 时，托盘中心以无弹窗、无卡片遮挡的文字提示低于常见建议范围，但仍可完成设计。
- [ ] 当前组装长度大于 20.0cm 时，以同样的非阻断方式提示高于常见建议范围，但仍可完成设计。
- [ ] 切换透明亚克力、米白骨瓷、原木、法式亚麻托盘后刷新页面，当前设计仍保留该展示偏好；托盘不进入价格与订单商品。
- [ ] “当前手串”区域可直接选择每一颗珠子，并可在同一水晶的可售规格间调整直径；手围与价格由 Backend 更新。
- [ ] 确认珠子保留水晶内部纹理、镜面高光和柔和圆形投影，整体仍为正面平面编辑画面。
- [ ] 点击保存，刷新页面；确认材料、revision 和价格仍然保留。
- [ ] 创建订单；确认返回 `PENDING` 状态及当前 revision/价格快照。

## 安全与体验抽查

- [ ] 在 360×800、375×667、390×844 和 430×932 CSS 视口复查核心页面：控制可读、可点，DIY 不溢出到不可操作区域。
- [ ] 在 1024×700、1280×720、1366×768、1440×900、1920×1080 和 2560×1440 桌面视口复查 DIY：页面无横向溢出，手串预览自适应，底部珠子货架可完整浏览。
- [ ] 用键盘 Tab 浏览主要按钮，焦点可见；主要触控目标约 44 px。
- [ ] 临时清空 Frontend token 并重启时，受保护请求明确失败，不会自动切换到 Mock 或固定用户。
- [ ] 页面不展示供应商、采购成本、`unitCostMinor` 或 Prisma 内部字段。

## 通过标准

核心验收项全部通过，且没有 BLOCKER、CRITICAL 或核心流程 MAJOR。
`INTERACTION_TEST_PLAN.md` 中的 P0 交互用例必须在电脑端和手机端 100% 通过。
如出现误删、重复添加、顺序损坏、保存丢失、价格/revision 由前端自行变化、
重复订单或无法恢复的交互死状态，应停止验收并记录为发布缺陷。
