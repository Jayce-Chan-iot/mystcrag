# Mystcrag MVP Development Plan

## Goal

Build the smallest complete commercial loop: AI design -\> DIY
modification -\> 3D preview -\> order generation.

## MVP Scope

### Must Have

-   Responsive web application
-   AI design questionnaire
-   Crystal recommendation
-   Design JSON generation
-   3D bracelet preview
-   Replace bead function
-   Price calculation
-   Save design

### Not First Priority

-   AR try-on
-   Complex social features
-   Advanced machine learning recommendation

## Acceptance Criteria

User can: 1. Enter preferences 2. Receive AI design 3. Modify bracelet
4. See price change 5. Save final design 6. Generate order information
