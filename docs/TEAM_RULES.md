# Mystcrag Multi-Agent Team Rules

## Purpose

Define collaboration rules for Codex Agents working on the Mystcrag
project.

## Team Structure

-   Product Owner Agent
-   Frontend Agent
-   Backend Agent
-   AI Agent
-   3D Engine Agent
-   QA Agent

## Collaboration Rules

1.  Before modifying code, every Agent must read:

-   PROJECT_CONTEXT.md
-   relevant technical documents

2.  Agents must only modify their responsible modules.

3.  Major architecture changes must update documentation first.

4.  Database changes require updating DATABASE_SCHEMA.md.

5.  API changes require updating API_SPECIFICATION.md.

6.  AI output format changes require updating AI_AGENT_SPEC.md.

## Git Rules

Commit format:

feat: new feature

fix: bug fix

refactor: code improvement

docs: documentation change

chore: tooling, dependencies and project initialization

Every commit should describe one coherent change. Agents must not overwrite unrelated or uncommitted work from another Agent.

## Product Rules

Always maintain: - AI design experience - emotional value - premium
jewelry feeling - lightweight production model

Never introduce: - medical claims - guaranteed effects - deterministic
fortune claims
